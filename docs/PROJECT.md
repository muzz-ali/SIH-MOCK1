# SIH Project — Gamified Learning Platform for Rural Education

STATUS: LOCKED
VERSION: v1.0

## Goal
Build a gamified learning platform for students in rural education contexts.

## MVP Features
- Student profile
- Approximately 200-question backend question bank
- Category/topic/difficulty metadata
- Quiz generation
- Answer submission and scoring
- XP and levels
- Daily challenges
- Streaks
- Weekly leaderboard
- Student progress
- Adaptive question selection
- AI-assisted recommendations
- AI answer explanations
- Responsive, low-bandwidth-friendly frontend

## Initial Categories
- General Knowledge
- Science
- Mathematics
- English
- Reasoning
- Computer/Digital Literacy

## Stack
Frontend: React + TypeScript + Vite + Tailwind CSS
Backend: Python + FastAPI
Database: PostgreSQL
AI: Server-side AI-assisted recommendation/explanation layer

## Product Principle
Reward learning progress and consistency, not merely existing academic ability.

## Locked requirement
AI agents and developers must not substantially change this scope without team approval.
